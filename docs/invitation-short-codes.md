# 邀请短码

StagePilot 的 Workspace 与 Production 邀请统一使用：

```text
/#/join/XXXXX-XXXXX
```

短码使用 10 位 Crockford Base32，展示为五位一组。输入时允许大小写、连字符和完整邀请链接；服务端会规范化后再校验。

## 作用域规则

- Workspace：必须指定邮箱，接受者必须使用已验证的相同邮箱；短码只能领取一次。
- Production：支持指定邮箱邀请，也支持 1–100 次领取的通用邀请。
- 邀请接受必须先登录；未登录用户会回到原短码地址完成登录后再接受。

## 复制与轮换

邀请列表不返回明文短码。管理员点击复制时调用邀请凭据接口，只读取当前短码，不生成新凭据。

`pending`、`scheduled`、`active` 邀请支持在原邀请记录上重新生成短码。轮换会保留角色、邮箱、有效期、领取计数和邀请 ID，旧短码立即失效。已过期、已撤销、已接受或已用尽邀请只能新建。

创建、复制和轮换响应包含短码与完整链接，并设置 `Cache-Control: no-store`。短码不会写入日志、Toast、分析事件或本地存储。

## 安全边界

短码只作为邀请凭据，不替代登录。服务端保存 HMAC hash，并使用 AES-GCM 密文支持管理员复制当前短码。接受接口按 IP 与账号进行失败尝试限流；邮箱不匹配、过期、撤销和用尽邀请不会泄露额外资源信息。
